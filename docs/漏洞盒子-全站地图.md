## 三、关键机制（从业余到能赚钱的分水岭）

### 1. 定级决定一切
平台用自己的 **CVSS 计算器**（`/cvss`）定级 → 等级直接决定奖金区间。
**提交前先自评一遍**，别按自己的感觉定级 ✗

### 2. 等级与福利（`/faq?id=114`）
白帽等级 ↔ 积分/奖金/权益。**等级越高，能进的项目越好**（部分项目有等级门槛）。

### 3. 三张"接活"入口（别只盯项目大厅）
```
① 项目大厅   —— 众测项目（主流）
② 免费闪测   —— 免费测试（低门槛、练手）
③ 任务大厅   —— 任务派发（按任务结算）
```

### 4. 提交规则的硬约束（帮助中心必读）
- 基本要求**实名**（练习阶段只做本地验证，暂不提交）
- **重复漏洞不给钱** → 提交前用「漏洞情报」查重
- 低危（缺响应头/self-XSS）多数项目**不收**

## 七、对我最有价值的三个结论

### 1. 官方给了清晰的「新人进阶路径」★
```
闪测大厅（低门槛）→ 展示实力拿"碎银" → 达标后【升级接"专属"项目】→ 独享赏金
```
→ 这条路**正是给你这种"还没实名/没有战绩"的人准备的** ✓
→ 实名后第一站应该是**闪测**，不是直接冲项目大厅 ✗

### 2. 积分/评级是两套独立系统，都要管
```
① 积分系统（赛季积分 / 总积分）：三维度 有效性 + 漏洞等级 + 报告质量
   → 说明"报告质量"直接影响积分 ✓ 报告写得好 = 积分多
② Rank 奖励：与积分【无关，独立计算】
③ 评级：用平台 CVSS 计算器（还分 A/B/C 类厂商）
```

### 3. "报告质量"是被明写的计分维度
→ 我之前的判断被平台规则**实证**：**同样的洞，报告写得好积分更多** ✓
→ 我们做的模板库/判据纪律（`enrich.py` + `报告模板.md`）方向正确 ✓
