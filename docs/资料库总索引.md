## 四、核心结论（浓缩版）

### 已验证的强项
```
1 Web 八类全能打（越权/认证/注入/XSS/SSRF/上传/逻辑/信息泄露）
2 移动 App：抓包 + 静态 + 原生hook + 重打包（Java层待换设备）
3 内网工作组：侦察→凭据→枚举→令牌解锁→哈希导出→PtH→远程执行→共享 全通
4 环境自建：VM/网络/隧道/靶场/域控 全都能从零搭
```

### 两个最值钱的实战知识点
```
· UAC 远程令牌过滤（LocalAccountTokenFilterPolicy）
  → "有管理员凭据却打不动"的头号原因
· SMB 签名 False = 可中继（内网横向核心前提）
```

### 明确的边界（不要浪费时间的地方）
```
✗ AD 取票据（Kerberoasting/DCSync/AS-REP）← Samba 域控不兼容，需真 Windows DC
✗ App Java 层逆向 ← Android 6 + frida 17 不兼容，需 Android 7+
✗ 抖音自动下载 ← 平台签名校验（403），换"用户提供文件"路线
✗ 免杀 ← 不在平台技能要求里，ROI=0，且有法律红线
```

### 唯一真正的瓶颈
```
真实度 = 0  ← 全部能力都在自建靶场验证，零真实项目经验
→ 满 18 岁后从平台【免费闪测】起步，真实反馈 > 再练 10 个靶场
```
