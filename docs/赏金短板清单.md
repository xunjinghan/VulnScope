## 一、按平台五类技能逐项体检

| 平台要求 | 我的现状 | 缺口 | 严重度 |
|---|---|---|---|
| **Web 漏洞** | ✅ 最强：8 类靶场全通（IDOR/认证/SQLi/XSS/SSRF/上传/逻辑/信息泄露） | ⚠️ 缺**高级类**：反序列化、SSTI、XXE、GraphQL、OAuth、支付逻辑<br>⚠️ 缺**真实系统复杂度**（靶场是简化的） | 🟡 |
| **App 客户端漏洞** | ⚠️ 抓包✓ 静态✓ 原生hook✓ | ✗ **Java 层逆向不可用**（Android 6 + frida 17 不兼容）→ 挖不到"签名算法/加密/硬编码密钥"这类**高分洞** | 🔴 |
| **逻辑漏洞** | ✅ 有判据（负数/并发/跳步/越权） | ⚠️ 缺**业务领域知识**（支付、风控、优惠券、订单状态机的真实玩法） | 🟡 |
| **情报信息收集** | ✅ recon.py + vulnbox.py scan（DNS/子域/端口/指纹） | ⚠️ 缺**规模化**：子域爆破字典、全端口、指纹库<br>⚠️ 缺 **API 发现**（Swagger/未授权接口/前端 JS 挖接口） | 🟡 |
| **内网渗透** | ✅ 工作组**全链条实测通过**（含 PtH + UAC 令牌过滤） | ⚠️ AD 取票据（需真 Windows DC）<br>⚠️ 中继（需 root + responder）<br>⚠️ 缺**代理隧道/多层内网**实战 | 🟡 |

```

```
**补法**：把"接单标准流程"升级成**带决策树**的版本（已有收网手册，缺决策层）

### ⭐ 3. 没见过真实被接受的报告
```
我有模板 + CVSS 定级 + 查重 ✓
但不知道怎么被"审核通过"（平台的隐性偏好）✗
```
**补法**：研究平台公开的漏洞案例 + 帮助中心规则；满 18 岁后从闪测拿第一次反馈
